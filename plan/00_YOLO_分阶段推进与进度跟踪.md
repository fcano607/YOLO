**辅助标注流程：**原始照片 → 现有 YOLO11n-seg 提议框 / 掩膜 → 人工确认每个商品类别、修正可见轮廓、删除误检并补齐漏检 → 导出类别 ID + 归一化多边形 → 标签检查 → 微调。模型可能漏检奶盒，试标时记录需手工重画的比例。单商品拍摄批次可预填类别，但混合图逐实例确认；不得把整个 COCO 的 cup / bottle 类统一改名为商品类。训练标签不写预测置信度，也不把分数改为 1 当成审核；保留原始照片，不用带文字 / 彩色掩膜的效果图训练。草稿与审核后的标签分开，验证 / 测试标签同样需人工核实。

拍摄覆盖多背景、光照、距离、角度、多个商品同框和部分遮挡；各类别使用相近背景与拍摄条件，避免背景与类别绑定。视频按片段抽帧去重，按拍摄组划分 train/val/test，不能随机拆分同一段连续帧。若每类只有一个实物，只能报告同包装在新场景的表现，不能宣称跨包装或跨批次泛化。分割标签标注整个包装的可见外轮廓，商品类别由人工确认，辅助轮廓必须修正。
