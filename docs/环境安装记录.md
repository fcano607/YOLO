## 6. 实际依赖安装与问题处理

先执行带约束的 `pip install --dry-run`。官方 PyPI 的 OpenCV 大文件下载停滞，终止该下载进程后改用清华镜像；dry-run 阶段没有安装包。镜像下载的 6 个发行包 SHA256 与官方 PyPI 元数据逐个匹配，实际安装报告也与这份核验清单一致。

实际安装命令，从项目根目录运行：

```powershell
& 'D:\software\anaconda\envs\yolo\python.exe' -m pip install `
    --no-build-isolation --timeout 30 --retries 2 `
    --index-url https://pypi.tuna.tsinghua.edu.cn/simple `
    --requirement requirements-train.txt `
    --report logs/environment/M0-02_20261002_pip_install.json
```

`--no-build-isolation` 使用环境已有的 setuptools 78.1.1 和 wheel 0.45.1；它们满足该源码的构建要求。Ultralytics 按 `-e ./third_party/ultralytics` 安装，修改该目录中的源码后，环境会加载对应代码。[官方源码安装说明](https://docs.ultralytics.com/quickstart/)

## 8. 目录、Git 与移机使用

已建立规划中的必要一级目录和 `artifacts/pretrained/`。路径清单为 [configs/paths.yaml](../configs/paths.yaml)，解析入口为 [deploy/paths.py](../deploy/paths.py)：相对路径从项目根目录解析；第三方库的数据 YAML 等文件仍需在调用时按其规则转换路径。

新项目副本的恢复顺序为：准备相同 Python/GPU PyTorch 环境 → 运行源码恢复脚本 → 安装 requirements → 创建本机数据和结果目录 → 运行验收脚本。当前 requirements 假定 GPU torch 已先安装，不能依靠普通 PyPI 自动选出 cu129 构建。

空目录不会随 Git 保存。移机时在项目根目录创建：

```powershell
foreach ($directory in @('data/fixed_checks', 'artifacts/pretrained', 'runs', 'demo', 'app')) {
    New-Item -ItemType Directory -Path $directory -Force | Out-Null
}
```

当前新环境由本机 tf2 克隆，尚未在另一台电脑或干净环境执行完整恢复；M0-06 还需验证重新启动后的 E0 与 ONNX。
