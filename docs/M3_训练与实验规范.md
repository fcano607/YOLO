## 3. 怎样选 best.pt，为什么有两个分数阈值

每轮用固定 5 张验证图计算框和掩膜指标。**best.pt 按验证集 `mask mAP50-95` 最高选择；并列时保存较晚的一轮。last.pt 保存最后一轮。** 不根据训练图表现或最终测试选择模型。

例如三轮的 mask 指标分别为 0.30 / 0.40 / 0.40，则第 3 轮保存为 best。这项规则已用“框指标最好的一轮与掩膜最好的一轮不同”的案例测试。

锁定源码默认的分割 fitness 是 box mAP50-95 与 mask mAP50-95 之和，见 [metrics.py](../third_party/ultralytics/ultralytics/utils/metrics.py)。本项目在 [MaskFirstSegmentationTrainer](../app/product_trainer.py) 中返回掩膜指标作为 fitness，沿用上游保存机制；没有修改第三方源码。

| 用途 | conf | 含义 |
| --- | --- | --- |
| 评价 mAP | 0.001 | 保留低分候选供评价器构建 Precision / Recall 曲线，不把画面显示阈值当评价门槛 |
| 查看预测图 | 0.25 | 显示达到该分数的框与掩膜，便于判断当前能否演示 |

两条路径固定 NMS IoU=0.7、max_det=300、不使用推理增强。NMS 的 0.7 是去重阈值；mAP50-95 的 0.50～0.95 是评价预测与真值匹配的 IoU 阈值，两者用途不同。最终测试 5 张继续封存；本入口 `--split test` 会被拒绝，测试模型推理留到 M8。
