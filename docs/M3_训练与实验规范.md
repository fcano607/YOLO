## 3. 怎样选 best.pt，为什么有两个分数阈值

每轮用固定 5 张验证图计算框和掩膜指标。**best.pt 按验证集 `mask mAP50-95` 最高选择；并列时保存较晚的一轮。last.pt 保存最后一轮。** 不根据训练图表现或最终测试选择模型。

例如三轮的 mask 指标分别为 0.30 / 0.40 / 0.40，则第 3 轮保存为 best。这项规则已用“框指标最好的一轮与掩膜最好的一轮不同”的案例测试。

锁定源码默认的分割 fitness 是 box mAP50-95 与 mask mAP50-95 之和，见 [metrics.py](../third_party/ultralytics/ultralytics/utils/metrics.py)。本项目在 [MaskFirstSegmentationTrainer](../app/product_trainer.py) 中返回掩膜指标作为 fitness，沿用上游保存机制；没有修改第三方源码。

| 用途 | conf | 含义 |
| --- | --- | --- |
| 评价 mAP | 0.001 | 保留低分候选供评价器构建 Precision / Recall 曲线，不把画面显示阈值当评价门槛 |
| 查看预测图 | 0.25 | 显示达到该分数的框与掩膜，便于判断当前能否演示 |

两条路径固定 NMS IoU=0.7、max_det=300、不使用推理增强。NMS 的 0.7 是去重阈值；mAP50-95 的 0.50～0.95 是评价预测与真值匹配的 IoU 阈值，两者用途不同。最终测试 5 张继续封存；本入口 `--split test` 会被拒绝，测试模型推理留到 M8。

## 7. M3-05：已完成的错误分析与改进路线

**当前模型已很好地拟合训练图，主要问题是换场景后的奶盒识别与轮廓。** 本轮使用同一个 E1 `best.pt`，分析固定 train20 / val5，未训练新模型。每类官方 box / mask AP 仍以第 6 节为准；本节增加逐实例匹配、低分候选和人工轮廓对照。

### 怎样比较，结果说明什么

从 conf=0.001 的同一后处理池检查 0.05 / 0.10 / 0.25 门槛；25 张图均未触及 max_det=300 上限。**按分数降序，同类且 IoU≥0.5 才一对一匹配**，框与掩膜分别计算；一个目标不能被多个预测重复算对。掩膜先去除 letterbox 补边、恢复原图坐标，再与人工多边形的像素区域比较。这是固定阈值诊断，不能当 mAP 或总体准确率。

| 池 / 类别 | 真值实例 | conf=0.25 框匹配 / 掩膜匹配 | 误检 / 漏检 |
| --- | --- | --- | --- |
| train / 山姆 | 12 | 12 / 12 | 0 / 0 |
| train / 伊利 | 10 | 10 / 10 | 0 / 0 |
| train / 瑞幸 | 8 | 8 / 8 | 0 / 0 |
| val / 山姆 | 2 | 0 / 0 | 0 / 2 |
| val / 伊利 | 3 | 1 / 1 | 0 / 2 |
| val / 瑞幸 | 3 | 3 / 3 | 0 / 0 |

训练图中匹配轮廓的最低 mask IoU 约 **0.933**、均值约 **0.964**，正确候选分数最低约 **0.843**。这些是看过的图片上的拟合表现，不能说明新场景也能成功。训练 30/30、验证 4/8 的差距支持“泛化与覆盖不足”的判断；不能据此单独证明模型只依赖背景，或把所有失败归因于某一个角度。

| val 显示阈值 | 框匹配目标数 | 掩膜匹配目标数 | 额外误检数 | 漏检数 |
| --- | --- | --- | --- | --- |
| 0.25 | 4/8 | 4/8 | 0 | 4 |
| 0.10 | 5/8 | 5/8 | 2 | 3 |
| 0.05 | 5/8 | 5/8 | 6 | 3 |

降到 0.05 只多找对 1 个小山姆盒，同时出现背景误检、定位不准的奶盒预测，以及一个把瑞幸杯预测为伊利的低分框。**降低显示阈值不能作为本轮模型改善的结论。** 验证负样本 005 在 0.05 和 0.25 均无检出；其他图片里的背景仍可能误检。
