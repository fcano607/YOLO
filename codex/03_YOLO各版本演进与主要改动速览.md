# YOLO 各版本演进与主要改动速览

整理日期：2026-10-02。阅读目标：快速了解常见 YOLO 版本改了什么、为什么改，以及这些变化与当前 YOLO11n-seg 项目的关系。

**YOLO 的改动主要围绕四件事：更好地提取特征、更准确地预测框、更有效地训练，以及更快地完成推理与部署。**

各版本来自不同团队，编号并不代表逐代完整继承。下面按技术重点组织，覆盖 YOLOv1—YOLOv12、YOLO26，并补充 YOLOX 这一重要分支；不是所有以 YOLO 命名的模型的完整清单。

## 1. 先看整体发展方向

| 技术重点 | 代表版本 | 主要解决什么问题 |
| --- | --- | --- |
| 建立统一检测框架 | YOLOv1 | 一次前向直接预测类别与框，让检测达到实时速度。 |
| 改善框表示与多尺度检测 | YOLOv2、YOLOv3 | 让框更容易学习，并兼顾大、中、小目标。 |
| 优化结构、训练与工程 | YOLOv4、YOLOv5、YOLOv6、YOLOv7 | 改善特征融合、数据增强、训练效果和实际部署效率。 |
| 改进预测头、标签分配与监督 | YOLOX、YOLOv8、YOLOv9 | 协调分类与定位，选择更合适的训练正样本，改善梯度信息。 |
| 探索端到端推理、注意力与部署 | YOLOv10、YOLO11、YOLOv12、YOLO26 | 分别从免 NMS 推理、特征结构、注意力和预测头简化等方向继续改进。 |

这些方向相互交叉。例如 YOLOv10 重点推进免 NMS 推理，YOLO11 重点优化特征结构，不能理解为 YOLO11 自动继承了 YOLOv10 的所有设计。

## 2. 各版本主要改动

版本名链接到原论文、作者源码或官方说明；表中列的是代表性改动，不是每个版本的全部实现细节。

| 版本 | 主要改动 | 可以怎样理解 |
| --- | --- | --- |
| [YOLOv1](https://arxiv.org/abs/1506.02640) | 将图像划分为网格，一次前向联合预测类别、框和置信度。 | 建立单阶段实时检测思路；小目标、密集目标和定位精度仍有不足。 |
| [YOLOv2](https://arxiv.org/abs/1612.08242) | 使用 Darknet-19，引入 anchor box、框尺寸聚类、BN、多尺度训练与细粒度特征融合。 | 用合适的框模板降低学习难度，并改善召回率与训练稳定性。YOLO9000 在此基础上结合检测和分类数据，扩展可识别类别。 |
| [YOLOv3](https://arxiv.org/abs/1804.02767) | 使用带残差连接的 Darknet-53，在三个尺度上预测，并融合不同层级的特征。 | 不同大小的目标有对应的预测尺度，尤其改善小目标检测。 |
| [YOLOv4](https://arxiv.org/abs/2004.10934) | 组合 CSPDarknet53、SPP、PAN 特征融合，以及 Mosaic 增强、CIoU 损失等策略。 | 通过系统组合结构与训练技巧，提高速度和精度的平衡。 |
| [YOLOv5](https://docs.ultralytics.com/yolov5/tutorials/architecture-description) | 以 PyTorch 工程化为重点，提供不同规模模型、自动 anchor、训练与导出工具；后续版本采用 C3、SPPF 等模块。 | 让模型更容易训练、使用和部署。原版 YOLOv5 是 anchor-based；后续 YOLOv5u 需单独区分。 |
| [YOLOX](https://arxiv.org/abs/2107.08430) | 采用 anchor-free、解耦预测头和 SimOTA 动态标签分配。 | 取消预设框宽高模板，将分类与定位分开，并动态选择哪些预测负责学习真实目标。 |
| [YOLOv6](https://arxiv.org/abs/2209.02976) | 面向工业应用，采用 EfficientRep、RepPAN、anchor-free 解耦头，并运用结构重参数化。 | 训练时保持表达能力，推理时合并结构，重视硬件上的实际执行速度。不同规模与后续版本的结构有差别。 |
| [YOLOv7](https://arxiv.org/abs/2207.02696) | 提出 E-ELAN，改进模型缩放、重参数化和辅助训练设计。 | 加强特征学习与梯度传递，在控制推理成本的同时提高检测能力。 |
| [YOLOv8](https://docs.ultralytics.com/models/yolov8/) | 采用 anchor-free 解耦头，更新特征提取与融合结构，并统一检测、实例分割、姿态估计等任务接口。 | 分类与定位分别学习，减少对预设框模板的依赖，工程使用方式更统一。 |
| [YOLOv9](https://arxiv.org/abs/2402.13616) | 提出 PGI（可编程梯度信息）和 GELAN（广义高效层聚合网络）。 | 改善训练中信息与梯度的传递，同时兼顾参数利用率和结构效率。 |
| [YOLOv10](https://arxiv.org/abs/2405.14458) | 提出一致双分配，训练时结合一对多与一对一监督；推理时使用一对一分支，并优化网络效率。 | 让模型学习减少重复预测，推理时省去额外的 NMS 去重步骤。 |
| [YOLO11](https://github.com/ultralytics/ultralytics/blob/main/ultralytics/cfg/models/11/yolo11.yaml) | 采用 C3k2 卷积模块和 C2PSA 注意力模块，改进特征提取与融合，并继续提供多任务模型。 | 重点优化特征结构及计算效率。常规 YOLO11 检测路径仍使用 NMS。 |
| [YOLOv12](https://arxiv.org/abs/2502.12524) | 以注意力为核心，提出区域注意力（Area Attention）和 R-ELAN，并结合 FlashAttention 等效率优化。 | 增强图像区域之间的关系建模，同时控制注意力计算的开销。它是独立研究分支。 |
| [YOLO26](https://docs.ultralytics.com/models/yolo26/) | 移除 DFL，简化框回归头；支持可选的免 NMS 推理；结合 MuSGD、Progressive Loss、STAL 等训练更新。 | 简化预测与部署，并改进优化和小目标监督。其默认一对多路径仍需 NMS，一对一路径支持免 NMS。 |

## 3. 表中常见术语

| 术语 | 简单解释 |
| --- | --- |
| Backbone / 主干 | 从图像中提取边缘、纹理、形状和语义等特征。 |
| Neck / 特征融合部分 | 融合不同分辨率、不同层级的特征，让定位细节和语义信息相互补充。 |
| Head / 预测头 | 根据特征输出类别、框，或掩膜、关键点等任务结果。 |
| Anchor box | 在特征位置预设的框宽高模板，模型学习如何调整这些模板。 |
| Anchor-free | 不依赖预设框宽高模板；仍然可以使用特征位置或参考点组织预测。 |
| 多尺度训练 / 多尺度预测 | 前者是在训练中改变输入尺寸；后者是在一次前向中使用多个分辨率的特征预测。二者不是同一件事。 |
| 解耦头 | 将分类与框定位分成不同预测分支，缓解两个任务对特征需求的冲突。 |
| 标签分配 | 决定哪些预测负责哪些真实目标，从而确定训练正样本。 |
| 结构重参数化 | 将训练时的多个分支等效合并为推理时更简单的结构。 |
| NMS | 非极大值抑制：对同一目标附近的重叠候选框进行筛选，减少重复检测。 |
| DFL | Distribution Focal Loss，分布焦点损失。用于监督框边界距离的分布式表示，相关实现再解码得到框。 |
| 注意力 | 根据特征之间的关系调整信息聚合方式，增强对相关区域或信息的利用。 |

## 4. 容易混淆的四件事

### 4.1 版本编号不是一条严格继承链

YOLOv1—v3 来自原始作者团队；YOLOv4、YOLOv7、YOLOv9 有共同研究者；YOLOv5、YOLOv8、YOLO11、YOLO26 属于 Ultralytics 系列；YOLOv6 来自美团团队；YOLOX、YOLOv10、YOLOv12 是其他团队的分支。

因此，不能只根据编号判断结构、训练方法、后处理或部署性能。

### 4.2 Anchor-free 不等于没有空间参考

Anchor-free 去掉的是预设宽高的框模板，不是空间位置。代码里的 `anchor_points` 可以指参考点，不能看到 `anchor` 这个词就断言模型使用 anchor box。

### 4.3 “端到端训练”与“免 NMS 推理”要分开

YOLOv1 已经强调用统一网络联合学习检测。但推理仍要筛选和去重候选框。YOLOv10 等模型讨论的端到端推理，进一步解决了依赖额外 NMS 后处理的问题。

### 4.4 模型规模与任务后缀不是新一代版本

例如 `YOLO11n-seg`：`YOLO11` 是模型系列，`n` 表示 nano 规模，`seg` 表示实例分割任务。同一系列的 `n/s/m/l/x` 是不同规模，不是不同代际；具体缩放规则按对应版本配置确认。

## 5. 与当前 YOLO11n-seg 项目的关系

当前项目面向杯子、瓶子、手机的实例分割。理解模型时，可以先抓住下面三点：

1. **特征来源：**YOLO11 使用 C3k2、C2PSA 等模块，并将不同层级的特征融合。
2. **多尺度预测：**本地配置使用 P3、P4、P5，步长分别为 8、16、32；这些是不同分辨率的特征，不是独立运行三个模型。
3. **分割输出：**`seg` 分支除类别和框外，还预测实例掩膜系数，并结合共享原型生成各个物体的轮廓。

结构依据见 [YOLO11-seg 官方配置快照](../ref/official_sources/ultralytics__cfg__models__11__yolo11-seg.yaml)，掩膜原理见 [现代检测与实例分割讲义](02_从YOLOv1到现代YOLO_检测与实例分割基础.md)。这些结构说明不等于当前项目的训练精度或速度结果；实际进度见 [项目进度跟踪](../plan/00_YOLO_分阶段推进与进度跟踪.md)。

## 6. 快速记忆与口头复述

**概念学习主线：v1 建立统一检测 → v2 引入框模板 → v3 多尺度预测 → YOLOX / v8 理解 anchor-free 与解耦头 → v10 / YOLO26 理解免 NMS 推理。**

这是一条帮助学习的概念路线，不表示这些版本逐代继承。v4—v7、v9、YOLO11、v12 分别从结构、训练、工程或注意力等方向继续改进。

可以这样口头回答：

> YOLO 最早把目标检测变成一次前向完成的类别和框预测。v2 引入 anchor 和更稳定的训练方式，v3 通过三尺度预测改善不同大小目标的检测。之后的模型不断优化特征融合、数据增强、预测头和标签分配，例如 YOLOX 和 v8 使用 anchor-free 解耦头。较新的改进方向包括 v10 的免 NMS 推理、YOLO11 的特征结构优化、v12 的注意力设计，以及 YOLO26 的预测头简化和部署优化。各版本来自不同团队，需要按具体实现比较。

后续学习按 [六阶段十八课学习手册](00_YOLO学习路线与学习手册_终极版.md)推进。当前项目应重点理解 YOLO11-seg，再按需学习 YOLOv10 和 YOLO26。

## 7. 原始资料与版本边界

- 每个版本的原论文或官方入口已链接在第 2 节；本地论文与源码文件见 [文献目录与来源](../ref/README_文献目录与来源.md)。
- YOLOv5、YOLOv6 等系列内部持续更新，模块不能不加版本限制地套用到所有早期实现。
- YOLO11 的本地配置与 [官方说明快照](../ref/official_sources/docs__en__models__yolo11.md)可用于对照；YOLO26 的双分支与 DFL 更新见 [官方说明快照](../ref/official_sources/docs__en__models__yolo26.md)。在线文档可能继续变化，工程运行以项目锁定版本为准。
- 这里不列跨论文的统一速度或精度排名，因为输入尺寸、硬件、推理后端、数据与测量范围可能不同。模型性能需要在相同条件下比较。
